# Moneta — 설치·동기화 가이드

폰(안드로이드)과 맥북에 각각 설치해서 쓰는 가계부 앱이에요. 데이터는 각 기기에 저장되고, 내 Firebase 프로젝트(구글 클라우드)를 통해 기기끼리 실시간으로 맞춰집니다. 구글 로그인은 한 번 하면 계속 유지돼요.

## 1. 앱 올리기 (GitHub Pages, 무료)

1. GitHub에서 새 저장소 만들기 (예: `salim`, **Public**)
   - 코드만 올라가고 가계부 데이터는 들어가지 않아서 공개 저장소여도 괜찮아요.
2. 이 폴더의 파일을 전부 업로드: `index.html`, `style.css`, `app.js`, `xlsx-lite.js`, `sw.js`, `manifest.webmanifest`, `icons/` 폴더
3. 저장소 **Settings → Pages → Branch: `main` / `(root)` → Save**
4. 1~2분 뒤 `https://<내 GitHub 아이디>.github.io/salim/` 주소로 접속돼요.

## 2. 기기에 설치

- **안드로이드**: 크롬으로 위 주소 열기 → 오른쪽 위 ⋮ → **앱 설치** (또는 홈 화면에 추가)
- **맥북**: 크롬으로 열기 → 주소창 오른쪽 설치 아이콘 → **설치** (사파리라면 파일 → Dock에 추가)

설치하고 나면 인터넷이 없어도 열리고 입력할 수 있어요.

## 3. 동기화 연결 — Firebase (처음 한 번만, 10분)

1. [Firebase 콘솔](https://console.firebase.google.com/) → **프로젝트 추가** → 기존 구글 클라우드 프로젝트(예: `salim`) 선택 → 애널리틱스는 꺼도 돼요
2. **Authentication → 시작하기 → 로그인 방법 → Google → 사용 설정** (지원 이메일 선택 후 저장)
3. **Authentication → 설정 → 승인된 도메인 → 도메인 추가**: `<내 GitHub 아이디>.github.io`
4. **Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**
5. Firestore **규칙** 탭에 이 폴더의 `firestore.rules` 내용을 붙여넣고 **게시** (내 계정만 내 데이터에 접근하게 잠금)
6. **프로젝트 설정(톱니바퀴) → 내 앱 → 웹(</>) 앱 추가** → 이름 Moneta → 나오는 `firebaseConfig`의 값 6개를 `config.js`에 붙여넣기
7. `config.js`를 GitHub에 올리고 앱을 다시 열기 → **설정 → 구글로 로그인**
8. 다른 기기에서도 앱을 열고 구글로 로그인하면 끝이에요. 그 뒤로는 로그인이 유지되고, 입력하면 다른 기기에 바로 반영돼요.

처음 로그인하면 이 기기에 있던 기록이 전부 Firebase로 올라가요. 다른 기기에서 고친 값이 더 최근이면 그 값이 남습니다.

## 4. 처음 세팅 순서

1. **설정 → 기본 설정 → 내 이름** 입력: 통장 내역에서 본인 계좌 간 이체를 구분하는 데 써요.
2. **설정 → 예산 시작일**: 달력 기준이면 1, 월급 기준으로 보고 싶으면 21
3. **가져오기**에서 신한카드·기업은행 엑셀 업로드 → 미분류 내역 분류
   - 내역을 수정할 때 "다음부터 이 카테고리로 자동 분류"에 체크하면 규칙이 생겨요. 같은 가맹점의 미분류 내역도 한 번에 분류됩니다.
   - 예: 김종선 → 관리비, 이주혁·이은비 → 정산·송금
4. 매일 쓰는 건 가운데 **+** 버튼으로 입력: 자주 쓰는 기록은 위쪽에 버튼으로 떠요.

## 5. 반복 기록 (v2)

설정 → 반복 기록에서 관리해요. 매월 정한 날짜가 되면 앱을 열 때 자동으로 기록됩니다.

- **확정**: 보험·기부·모임계·저축처럼 금액이 같은 항목은 정한 금액 그대로 기록돼요.
- **예정**: 대출이자·관리비·통신비처럼 조금씩 바뀌는 항목은 "확인 필요"로 기록돼요. 홈에서 눌러 실제 금액으로 고치거나, 엑셀을 가져오면 같은 카테고리·비슷한 날짜(±10일)의 실제 내역으로 자동 확정됩니다. 이때 새 내역이 따로 추가되지 않아서 중복이 생기지 않아요.
- 기록된 반복 내역을 지우면 그달에는 다시 생기지 않아요.

## 6. 기존 설치본 업데이트

GitHub 저장소에 새 파일을 덮어써서 올린 다음, 각 기기에서 앱을 **한 번 닫았다가 두 번 열면** 새 버전이 적용돼요. 기존 데이터와 동기화 연결은 그대로 유지됩니다.

## 7. 데이터 보호

- 앱을 다시 설치하거나 브라우저 저장소가 지워져도, **구글로 로그인만 하면** Firebase에서 데이터가 돌아와요.
- 동기화가 꺼진 상태(로그인 안 함)에서는 앱을 삭제하면 기기의 데이터가 같이 지워질 수 있어요. 백업(JSON 내보내기)을 가끔 받아두세요.
- 설정 맨 아래에 이 기기 저장소가 "보존 모드"인지 표시돼요.

## 8. 알아둘 점

- **백업**: 설정 → JSON으로 내보내기. 동기화와 별개로 한 달에 한 번 정도 받아두세요.
- **엑셀 형식**: .xlsx와 .csv를 읽어요. 구버전 .xls는 엑셀에서 .xlsx로 저장한 다음 올려주세요.
- **업데이트**: 파일을 고쳐서 다시 올리면, 앱을 다시 열 때 새 버전이 적용돼요 (`sw.js`의 VERSION 숫자도 올려주세요).
- 같은 내역을 두 기기에서 동시에 고치면 나중에 고친 쪽이 남아요.
